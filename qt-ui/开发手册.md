## 1. 系统烧录与内存适配

### 1.1 镜像说明
你使用的是飞腾官方提供的 `2-Ubuntu_xfce` 镜像。该镜像为 2GB 与 4GB 版本通用镜像，但对于 **2GB DDR 颗粒（兆易创新 GigaDevice）** 的飞腾派，烧录后**必须**在 SD 卡底层写入内存大小适配标识，否则系统无法顺利引导。

### 1.2 烧录步骤
1. 准备一张 **32GB 或以上** 的高速 MicroSD 卡（建议闪迪 A1/A2 级别）。
2. 使用 `SDCardFormatter` 将卡格式化为 **FAT32**。
3. 使用 `balenaEtcher` 将镜像压缩包解压后的 `.img` 文件写入 SD 卡。

### 1.3 2GB 内存标识适配（关键步骤）
烧录完毕后，不要直接拔出 SD 卡。将其连接到 Linux 系统（可以是 WSL、虚拟机或另一台 Linux 主机），在终端下执行以下数据块写入操作：

```bash
# 1. 查找 SD 卡的设备节点（通常为 /dev/sdb 或 /dev/sdc，千万不要填错！）
ls /dev/sd*

# 2. 将下面 sdx 替换为你的 SD 卡实际节点（例如 sdb）
sudo printf "\x0F" | dd of=/dev/sdx bs=1 count=1 conv=notrunc seek=1004390
sudo sync
```
*注：该操作会在固定的引导配置偏移处写入 `0x0F`，告诉引导加载程序限制为 2GB 寻址，从而保证稳定启动。*

### 1.4 默认账户
* **用户名**：`user`
* **密码**：`user`
* **Root 权限**：使用 `sudo`，密码同上。

## 2. 飞腾派连接与同步开发流

为了保证开发的高效性，建议使用 **Windows 编辑 + SSH 同步 + 飞腾派编译** 的跨平台开发工作流。

```
Windows 电脑（VS Code / Qt Creator）
       │
       ├─[编辑代码] ──► 保存自动同步 (VS Code Remote-SSH / SCP)
       ▼
飞腾派（连接在同一局域网下）
       │
       ├─[终端] ──► qmake && make -j4 编译
       ▼
HDMI 显示器 ──► 实时全屏预览 Apple 风格 UI
```

### 2.1 基础连接方式
1. **网线/WiFi 连接**：将飞腾派与 Windows 电脑置于同一路由器下。在串口或本地终端通过 `ip addr` 确认飞腾派 IP（例如 `192.168.1.105`）。
2. **MobaXterm 工具**：在 Windows 上打开 MobaXterm，新建 SSH 会话，输入 IP 和用户名 `user` 即可直接掌控终端。它左侧自带 SFTP 窗口，可拖拽传输文件。
3. **VS Code 远程开发（终极推荐）**：
   * 在 Windows 上的 VS Code 安装 `Remote - SSH` 插件。
   * 添加连接 `ssh user@192.168.1.105`。
   * 连接后直接在 VS Code 里打开飞腾派上的项目目录 `~/PhytiumCarUI`，保存代码时飞腾派上立即更新，体验与本地开发无异。

## 3. 飞腾派 Qt QML 环境搭建

飞腾派系统镜像已预装了基础的 Qt 5.12.8 以及 QMake 3.1。为了让 QML 支持毛玻璃特效、多媒体摄像头以及串口通信，必须通过 APT 安装相关的开发库和 QML 模块：

```bash
# 1. 更新包管理器缓存
sudo apt-get update

# 2. 安装 Qt 编译核心及开发头文件
sudo apt-get install -y build-essential qt5-default qtdeclarative5-dev

# 3. 安装 QML 核心及控制组件（Qt Quick Controls 2）
sudo apt-get install -y qml-module-qtquick2 qml-module-qtquick-window2 qml-module-qtquick-controls2

# 4. 安装毛玻璃与高画质渲染必不可少的图形特效模块
sudo apt-get install -y qml-module-qtgraphicaleffects

# 5. 安装串口通信与多媒体摄像头组件
sudo apt-get install -y qml-module-qtmultimedia qtmultimedia5-dev libqt5multimedia5-plugins
sudo apt-get install -y libqt5serialport5 libqt5serialport5-dev qml-module-qtserialport

# 6. 用户组权限设置（确保 user 账号有权读写串口与摄像头）
sudo usermod -aG dialout user
sudo usermod -aG video user
```
*提示：安装完成后，建议重启飞腾派以使组权限更改生效。*

## 4. 项目架构与代码设计

项目 `PhytiumCarUI` 采用了 **C++ 提供底层高频数据/串口通信 + QML 构建 Apple 级视觉层** 的高效架构，最大化利用了飞腾派的 GPU 硬件加速。

### 4.1 目录结构
```
PhytiumCarUI/
├── PhytiumCarUI.pro          # QMake 工程配置文件，定义模块与源文件
├── main.cpp                  # 应用程序入口，设置环境并加载 QML 引擎
├── qml.qrc                   # Qt 资源文件，打包 QML 组件防止丢失
├── qml/                      # QML 源码目录
│   ├── main.qml              # 主界面框架，全屏自适应，入场滑入动画
│   ├── components/           # 复用组件目录
│   │   ├── Theme.qml         # [单例] 样式常量（色彩、圆角、字号、动画参数）
│   │   ├── qmldir            # 声明单例模块
│   │   ├── GlassCard.qml     # 基础毛玻璃卡片（含发光边框与内阴影）
│   │   ├── SpeedGauge.qml    # 速度圆弧仪表（Canvas 动态高性能重绘）
│   │   ├── BatteryIndicator.qml # 电池状态（含电压数值与平滑电量条）
│   │   ├── TemperatureDisplay.qml # 温度看板（随温度高低变色）
│   │   ├── PositionDisplay.qml  # 经纬度位置（高精排版）
│   │   ├── StatusBar.qml     # 底部状态栏（显示串口、WiFi、FPS 与运行时间）
│   │   ├── PanelListCard.qml # 光伏板滚动状态列表（支持状态微标）
│   │   └── PanelDetailModal.qml # 光伏板详情模态弹窗（带 scale 缩放滑入）
└── src/                      # C++ 后端代码目录
    ├── vehicledata.h/.cpp    # 车辆实时状态模拟（5Hz 刷新，双向绑定）
    └── panelmodel.h/.cpp     # 光伏板列表数据模型（支持状态随机变更测试）
```

### 4.2 核心代码设计解析
* **自适应与缩放比例**：在 `main.qml` 中，通过 `readonly property real sf: Math.max(0.65, Math.min(height / 1080.0, width / 1920.0))` 计算自适应缩放因子 `sf`。组件的字号、间距均乘以 `sf`，从而完美适配从 720P 到 4K 的任意 HDMI 显示器。
* **模拟数据源 (C++)**：`VehicleData` 使用 `QTimer` 模拟了小车行进过程中的速度（正弦波动）、电量（缓慢下降）及经纬度漂移。`PanelModel` 继承自 `QAbstractListModel`，不仅提供了高性能的列表数据项绑定，还每隔 8 秒模拟改变一个光伏板的异常状态，用来验证 UI 刷新。

## 5. 自适应与无触摸设计（HDMI 自适应）

为满足**第一 HDMI 屏幕自适应**与**第二不需要触摸（使用物理按钮或免触交互）**的指标，我们进行了专项优化设计：

### 5.1 HDMI 屏幕多分辨率完美自适应
* **全屏锁定**：QML 采用 `visibility: Window.FullScreen`，在飞腾派启动时自动捕获 HDMI 显示器的物理宽高，并以全屏模式渲染。
* **比例布局（Relative Layouts）**：左右侧边卡片宽度采用 `parent.width * 0.23` 比例，中间视频区域宽度动态填满剩余空间，避免了写死像素导致的排版错乱。
* **字号自适应**：
  ```qml
  Text {
      text: "状态仪表盘"
      font.pixelSize: Math.max(12, 18 * sf) // 配合缩放因子 sf，在小屏上依然清晰可读
  }
  ```

### 5.2 无触摸全自动/按键交互设计
由于巡检场景不需要人工去屏幕上指指点点，界面交互必须设计为**免触式**或**物理按键驱动**：
1. **信息全轮播/故障全弹窗**：当光伏板发生严重故障（如 `DAMAGED`）时，系统可由后端直接发出信号触发 `PanelDetailModal` 的自动弹出，无需手动点击。
2. **自动状态轮巡**：系统内置状态轮播逻辑，可按顺序展示不同光伏板的监测数据。
3. **极简物理键盘/手柄映射**：QML 支持完全的 `Keys` 附加属性绑定。可配合小车上引出的物理微动开关（通过 GPIO 映射为键盘的左右键、确认键）来实现免触控的物理按键操作：
   ```qml
   Item {
       focus: true
       Keys.onLeftPressed: { /* 切换到上一个光伏板 */ }
       Keys.onRightPressed: { /* 切换到下一个光伏板 */ }
       Keys.onReturnPressed: { /* 弹出/关闭详情模态框 */ }
   }
   ```

## 7. USB 摄像头视频流集成（QtMultimedia）

在第一阶段的模拟运行通过后，你将接上真实的 USB 摄像头。利用 Qt 预置的底层硬件加速，在 QML 中集成视频背景极其简单，性能远超 Python MJPEG 传输。

### 7.1 QML 视频渲染方案
打开 `main.qml`，定位到 `// 中央视频流区域`。一旦摄像头就位，可以用如下高性能 QML 结构直接替换占位 `Rectangle`：

```qml
import QtMultimedia 5.12

Item {
    id: centerArea
    anchors.left: dashboardCard.right
    anchors.right: panelCard.left
    anchors.top: parent.top
    anchors.bottom: statusBar.top
    anchors.margins: marginSize

    // 底层视频画面
    Camera {
        id: usbCamera
        deviceId: "/dev/video0" // 默认第一路 USB 摄像头
        captureMode: Camera.CaptureViewfinder
    }

    VideoOutput {
        id: videoOutput
        source: usbCamera
        anchors.fill: parent
        fillMode: VideoOutput.PreserveAspectCrop // 保持比例裁剪填充
        
        // 设置毛玻璃卡片的圆角裁剪
        layer.enabled: true
        layer.effect: ShaderEffect { /* 硬件级圆角裁剪 */ }
    }
}
```

### 7.2 摄像头物理通道测试
在编写代码前，可以在飞腾派终端通过系统工具确认摄像头是否能够工作：

## 8. 下位机 STM32 串口协议与 C++ 接入

小车的实时数据需要通过底层串口（UART）获取。我们将 STM32 上的数据通过 USB-TTL 串口发送给飞腾派。

### 8.1 串口数据协议定义（二进制高可靠帧）
* 帧头：`0xAA 0x55`
* 波特率：`115200`，`8N1`

#### 上行帧格式（STM32 ──► 飞腾派，每 100ms 一帧）
| 字节偏移 | 字段名 | 数据类型 | 物理含义 |
| :--- | :--- | :--- | :--- |
| `0 - 1` | Header | `uint8_t[2]` | 帧头固定为 `0xAA, 0x55` |
| `2` | Length | `uint8_t` | 数据字节长度（校验位前） |
| `3` | Speed | `int16_t` | 实时速度，单位 `mm/s` |
| `5` | Voltage | `uint16_t` | 电池电压，单位 `mV` |
| `7` | Temperature | `int8_t` | 控制器温度，单位 `℃` |
| `8` | FaultCode | `uint8_t` | 故障状态码 |
| `9` | CheckSum | `uint8_t` | 校验和（从字节 3 到 8 的异或校验） |

### 8.2 Qt C++ 串口接收实现（多线程不占 UI 帧率）
在 `PhytiumCarUI` 项目中，我们可以编写 `SerialManager` 类，用 `QSerialPort` 异步读取 `/dev/ttyUSB0` 数据并反序列化，最后更新 `VehicleData` 的各项属性。QML 会依靠信号槽机制自动、顺滑地重绘表盘。

```cpp
// 核心解析结构示例：
void SerialManager::readData() {
    m_buffer.append(m_serial->readAll());
    while (m_buffer.size() >= 10) {
        if (static_cast<uint8_t>(m_buffer[0]) != 0xAA || static_cast<uint8_t>(m_buffer[1]) != 0x55) {
            m_buffer.remove(0, 1); // 错位检索帧头
            continue;
        }
        
        // 计算并校验 CheckSum
        uint8_t checksum = 0;
        for (int i = 3; i < 9; ++i) checksum ^= m_buffer[i];
        if (checksum != static_cast<uint8_t>(m_buffer[9])) {
            m_buffer.remove(0, 2); // 校验失败，剔除损坏帧
            continue;
        }
        
        // 解析数据并映射至全局对象
        int16_t rawSpeed = (m_buffer[4] << 8) | m_buffer[3];
        uint16_t rawVolt = (m_buffer[6] << 8) | m_buffer[5];
        int8_t rawTemp = m_buffer[7];
        uint8_t rawFault = m_buffer[8];
        
        m_vehicleData->updateFromHardware(rawSpeed / 1000.0, rawVolt / 1000.0, rawTemp, rawFault);
        m_buffer.remove(0, 10);
    }
}
```

## 9. 光伏板 AI 检测与 QML 界面集成

在第 4 阶段，你需要将运行在飞腾派上的 AI 目标检测模型（如 YOLOv8n-ONNX，飞腾派 NPU 可顺畅跑 15+ FPS）与 Qt UI 进行连接。

### 9.1 通信链路设计
AI 检测脚本通常由纯 Python（OpenCV + ONNX Runtime / Phytium NPU SDK）编写。为了将检测到的**光伏板 ID**、**状态（破损/正常）**、**置信度**传给 C++ 的 `PanelModel` 渲染，推荐采用以下高并发架构：

```
[ YOLOv8 摄像头检测进程 (Python) ] 
               │  以极轻量的 JSON 格式发送局域网封包
               ▼  TCP Socket / QLocalSocket
[ PhytiumCarUI 主应用程序 (C++) ]
               │  解析数据，通过 QAbstractListModel 数据流触发 QML 更新
               ▼
[ QML 列表 & 详情模态框 ] ──► 绚丽呼吸警报动画与音效
```

### 9.2 通信数据格式（极简 JSON 帧）
```json
{
  "panel_id": "PV-002",
  "status": "DAMAGED",
  "confidence": 0.94,
  "voltage": 32.4,
  "current": 5.2
}
```
当 C++ 接收到此数据后，调用 `PanelModel::updatePanel(id, status, confidence)`，右侧光伏板卡片就会立即刷新（变为红底警示），同时状态栏响起柔和警报。

## 10. 系统自启动与商业级演示优化

为了在研电赛决赛或者演示现场达到“开机即现 UI”的商业级水准，我们需要配置应用开机自动全屏启动。

### 10.1 编写自启动服务脚本
在飞腾派上创建启动脚本 `/home/user/start_car_ui.sh`：
```bash
#!/bin/bash
# 1. 延迟 3 秒，确保 X11 图形环境以及系统的 GPU 驱动已完全就绪
sleep 3
export DISPLAY=:0
export QT_QPA_PLATFORM=xcb

# 2. 启动 QML 主界面
/home/user/PhytiumCarUI/PhytiumCarUI --fullscreen
```
添加执行权限：
```bash
chmod +x /home/user/start_car_ui.sh
```

### 10.2 加入 XFCE 开机自启列表
由于飞腾派使用的是 Ubuntu XFCE 桌面镜像，最简单的自启动方法是将其加入 XFCE 会话管理器：
1. 打开 XFCE 应用菜单 -> 设置 -> `Session and Startup`（会话和启动）。
2. 选择 `Application Autostart`（应用程序自启动）选项卡。
3. 点击 **Add**（添加），填入：
   * **Name**: `Phytium Car UI`
   * **Command**: `/home/user/start_car_ui.sh`
4. 保存重启飞腾派。只要飞腾派一开机进入桌面，就会瞬间拉起这个科技感拉满的全屏毛玻璃仪表盘！
