# 基于飞腾派的沙戈荒光伏巡检系统

## 1. 项目简介

本项目面向沙戈荒大型光伏场景，设计一套基于飞腾派的光伏巡检系统，实现移动巡检、数据采集、异常识别、状态展示等功能。

## 2. 项目模块

- stm32：下位机底盘控制、电机控制、编码器测速、PID控制
- phytium：飞腾派上位机控制、串口通信、任务调度
- vision：图像识别、光伏板异常检测
- ui：人机交互界面
- docs：开发文档、接线说明、调试记录
- hardware：硬件接线、结构、电源方案
- test：测试代码和验证脚本

## 3. 分支规范

- main：稳定版本，必须保证可运行
- feature/xxx：功能开发分支
- fix/xxx：问题修复分支
- docs/xxx：文档分支

## 4. 提交规范

提交信息格式：

- feat: 新功能
- fix: 修复问题
- docs: 文档更新
- refactor: 代码重构
- test: 测试相关
- chore: 杂项调整

示例：

feat: 添加STM32速度环PID控制
fix: 修复右侧电机方向反转问题
docs: 更新飞腾派与STM32串口接线说明
