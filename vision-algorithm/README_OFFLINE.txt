飞腾派脱机调试指南 (Offline Debugging Guide)
==============================================

为了方便您将飞腾派安装到小车上进行脱机（无屏幕、无键盘）测试，我们为您准备了这个优化版本的代码目录。

### 主要优化内容：
1. **自动重启保护**：新增了 `start_offline.sh` 脚本，如果 Python 程序意外崩溃（比如摄像头接触不良掉线），它会在 3 秒后自动重启。
2. **离线日志记录**：脚本会自动截获所有屏幕上的输出（包括错误报错），并按照当前时间生成日志文件（如 `offline_debug_20260615_163000.log`）。测试完毕后，您可以直接用 U 盘拷贝这些日志在电脑上分析。
3. **取消了输出缓冲**：使用了 `python3 -u`，确保程序哪怕突然断电，最后那一刹那的日志也能被实时写入文件。

### 如何在飞腾派上使用：
1. 请将整个 `6-15-16-30-飞腾派脱机调试优化版` 文件夹拷贝到飞腾派的桌面上。
2. 在飞腾派终端中进入该目录：
   cd /home/user/Desktop/PhytiumProject/6-15-16-30-飞腾派脱机调试优化版
3. 赋予脚本执行权限：
   chmod +x start_offline.sh
4. 运行脱机启动脚本：
   ./start_offline.sh

（如果您希望飞腾派开机自动运行，可以考虑将 `/home/user/Desktop/PhytiumProject/6-15-16-30-飞腾派脱机调试优化版/start_offline.sh` 加入到 Linux 的 `rc.local` 或者 systemd 启动服务中。）

### 祝测试顺利！
