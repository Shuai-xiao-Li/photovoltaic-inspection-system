# 飞腾派边缘端视觉检测加速系统 — 研电赛提交版

## 一、 项目简介
本项目为全国研究生电子设计竞赛参赛作品——“沙漠光伏板检测机器人系统”的上位机智能视觉算法与核心部署平台。

上位机采用 **飞腾派（Phytium Pi）V2.0** 异构四核处理器作为核心硬件底座，部署我们自主训练的沙漠光伏板故障异常检测深度学习模型。为解决边缘端算力有限、神经网络模型推理耗时长、系统温升过高导致设备降频等问题，我们团队针对飞腾派芯片的硬件架构，设计并开发了**“异构核心多线程流水线调度 + 自适应帧间差分目标过滤 + ONNX Runtime INT8 量化推理”**的高性能边缘端视觉检测加速方案。

*   **设计开发团队**：李帅、赵禹博、吴坨鑫
*   **开发日期**：6月12号

## 二、 核心加速与优化技术

### 1. 异构核心多线程流水线
飞腾派拥有不同能效比的异构计算核心。如果采用单线程串行架构，图像读取、图像预处理和神经网络推理将互相阻塞，导致帧率严重下降且大核长期处于等待状态。
我们设计了多线程并发流水线：
*   **采集与过滤线程**：绑定在飞腾派的小核心上，负责高频读取摄像头帧、色彩修复及帧间差分计算。
*   **AI推理线程**：绑定在高性能大核心上，从缓冲队列中提取通过差分过滤后的待检测图像，执行高负荷的深度推理。
这使系统实现了“小核高频过滤，大核按需推理”的高能效架构。

### 2. 自适应帧间差分目标过滤
为降低大核空转率、控制芯片温度，我们在流水线中加入了帧间差分判定算法：
*   对连续帧进行灰度化与差分处理，当画面变化量低于自适应阈值时，认为画面无变化（即无新光伏板进入），直接重用上一帧的检测框与置信度，从而**跳过耗能的大核神经网络推理阶段**。
*   当差分判定画面有明显变化或超过一定周期（强制刷新周期）时，才重新触发 ONNX 推理。此项优化大幅降低了系统的整体功耗与运行温升。

### 3. ONNX Runtime INT8 量化部署
为实现极速的边缘推理，我们移除了庞大的 PyTorch 推理库及 FP32 ONNX 冗余模型，仅保留针对 `solar_panel_int8.onnx`（23.6MB）量化模型的推理支持：
*   **纯 NumPy 预处理**：放弃了重型的 `PIL` 和 `torchvision`，完全使用纯 NumPy 的向量化矩阵运算完成 HWC 到 CHW、归一化与 Batch 维度的扩张。
*   **ARM NEON 硬件加速**：启用 `onnxruntime` 自带的 ARM CPU NEON 指令集底层优化，使得原本数百毫秒的推理，在飞腾派单核上只需十毫秒级即可完成。

### 4. 串口控制与脱机保护
上位机通过串口（`serial_bridge.py`）以 115200 波特率同底盘 STM32 保持高频数据交互：
*   **PID航向纠偏对准**：通过计算检测目标中心与图像物理中心的水平像素偏差，将偏差以差分指令发送给底盘，指导底盘实现物理对准与跟踪。
*   **脱机监控自拉起**：提供了 `start_offline.sh` 脚本，在脱机工作时可自动拉起崩溃的视觉进程，并以时间为名实时保存串口和异常日志，以便离线导盘分析。

## 三、 代码结构与说明

提交版移除了与 INT8 ONNX 部署无关的训练权重（`.pth`）及未量化模型（`fp32.onnx`），主要程序如下：
*   `realtime_detector_accel.py`：主控制状态机与流水线调度，读取相机，在检测到异常时向底盘发布减速、截图和对准指令，并将状态及BMP画面实时输出给 Qt UI。
*   `phytium_accelerator.py`：飞腾派调度器核心，实现大核推理绑定、FrameDiff 差分逻辑、`ONNXInferenceEngine` 加速推理引擎以及云台追踪防抖计算。
*   `serial_bridge.py`：上位机串口驱动，负责将视觉检测的偏置量打包为串口协议帧发送给 STM32。
*   `benchmark.py`：性能评测基准程序，用于测试飞腾派在加载 `solar_panel_int8.onnx` 时的平均耗时以及运行 CPU 温升压力测试。
*   `start_offline.sh`：自动守护进程脚本，重定向 stdout/stderr 输出为无缓冲的本地 log 日志，崩溃后 3 秒自重启。

## 四、 快速部署与运行步骤

1.  **拷贝代码**：
    将本 `飞腾派视觉算法提交版` 文件夹拷贝到飞腾派的桌面上，确保当前目录下已包含 `solar_panel_int8.onnx` 权重。
2.  **安装运行时依赖**：
    在飞腾派终端运行：
    ```bash
    pip3 install onnxruntime opencv-python numpy
    ```
3.  **脱机启动运行**：
    赋予脚本执行权限并启动：
    ```bash
    chmod +x start_offline.sh
    ./start_offline.sh
    ```
    程序会以 `offline_debug_[时间戳].log` 形式无缓冲实时在本地写入日志，拔下串口或突然断电也能保存崩溃前的最后一帧报错。
4.  **基准性能测试**：
    若需单独测试量化模型的单帧推理速度与散热压力，可以运行：
    ```bash
    python3 benchmark.py --stress 5
    ```
    运行 5 分钟的满载压力推理测试，并实时打印当前 CPU 的工作温度。
