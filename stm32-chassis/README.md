# 履带式智能小车底盘运动平台控制系统 — 研电赛提交版

## 一、 项目简介
本项目为全国研究生电子设计竞赛参赛作品——“沙漠光伏板检测机器人系统”的智能履带小车底盘运动平台下位机控制系统。

底盘选用 **STM32F103ZET6** 精英开发板作为核心主控，搭载六轴惯性传感器 **MPU6050** 与双路大功率驱动器，控制一套双侧双电机的履带差速行进底盘。针对履带车物理运动特性（打滑系数不均、重心非绝对对称以及地面摩擦扰动大）造成的行驶跑偏难题，我们团队设计并实现了**“外环绝对偏航角（Yaw）方位角 PID 纠偏 + 内环两侧速度 PI 闭环”**的串级混合控制系统，彻底实现了底盘的绝对直线锁死和精准航向自适应控制。

*   **设计开发团队**：李帅、赵禹博、吴坨鑫
*   **开发日期**：6月12号

## 二、 核心技术特色与控制演进

### 1. 串级差速航向锁死算法
在早期开发中，底盘使用双侧电机增量式速度环控制，虽然能够确保“两侧轮子的编码器读数严格对齐”，但落地带载运行时仍会因为打滑和路面不平产生倾斜。
为解决此痛点，我们引入 MPU6050 采集绝对偏航角（Yaw）作为航向反馈，设计了本算法：
*   **航向外环控制**：计算目标航向与实际 Yaw 角的偏差 $e(t)$，通过位置式 PID 控制器计算出纠偏差速补偿量 $U_{\text{turn}}$。
*   **速度内环控制**：将纠偏量 $U_{\text{turn}}$ 作为差速补偿，实时叠加至内环速度目标中：
    $$\text{Left Target Speed} = \text{Base Speed} - U_{\text{turn}}$$
    $$\text{Right Target Speed} = \text{Base Speed} + U_{\text{turn}}$$
    当外部扰动导致车头偏左时，系统在 10ms 周期内迅速降低左轮速度并提升右轮速度，从而产生右向差速，瞬间将航向拉正。

### 2. 驱动板断电防倒灌安全保护
小车底盘的动力电池电压较高（12V），为防止驱动板断电而单片机仍上电时，STM32 控制引脚的高电平向驱动器倒灌产生 IO 损耗甚至烧毁硬件，我们在程序中集成了 `PA5 ADC` 动力监测保护机制：
*   单片机实时读取驱动板的 12V 动力电源电压，当判断驱动板处于断电（`OFF`）状态时，立即将所有电机控制引脚（`PA6/PA7/PE0/PE1/PE2/PE6`）配置为模拟高阻输入状态，彻底切断物理通路，保护了整机电路。

### 3. 本地无闪烁 LCD 双调参仪表盘
为方便脱机部署调试，我们设计了专用的本地 LCD 显示系统：
*   **局部对比刷新算法**：仅在数据变化时重绘特定行，并用空格填充旧字符，规避了高频清屏引起的 TFTLCD 强烈频闪。
*   **Speed 速度环调参页面**：实时查看/修改双侧电机速度内环的 `KP`、`KI` 参数与运行目标速度。
*   **Turn 航向环调参页面**：在线调节方位环 `KP`、`KI`、`KD` 参数，实时反馈实际偏航角与差速补偿输出。

## 三、 硬件引脚与接线定义

为防止外设硬件与精英板载 EEPROM、LCD 触摸屏等发生引脚冲突，请严格按照下表进行电气连接（**通电前务必拔掉开发板上的 P7 跳线帽**）：

| 功能模块 | STM32 引脚 | 定时器/通道资源 | 驱动板引脚 | 说明与安全保障机制 |
| :--- | :--- | :--- | :--- | :--- |
| **左侧电机 PWM** | `PA6` | `TIM3_CH1` | D153B `PWMA` | 避开 LCD 触摸 SCK（`PB1`） |
| **右侧电机 PWM** | `PA7` | `TIM3_CH2` | D153B `PWMB` | 避开 LCD 背光控制（`PB0`） |
| **左侧方向控制** | `PE0`, `PE1` | 普通 GPIO | D153B `AIN1/2` | 控制左侧电机正反转 |
| **右侧方向控制** | `PE2`, `PE6` | 普通 GPIO | D153B `BIN1/2` | 控制右侧电机正反转 |
| **左编码器脉冲** | `PC6`, `PC7` | `TIM8_CH1/2` | 编码器 `E1A/B` | 避开板载 EEPROM （`PB6/7` 强上拉） |
| **右编码器脉冲** | `PA0`, `PA1` | `TIM2_CH1/2` | 编码器 `E2A/B` | **必须拔下 P7 触摸按键跳线帽** |
| **驱动板动力电压**| `PA5` | `ADC1_IN5` | D153B `ADC` | 读取 12V 实测电压，实施防倒灌保护 |
| **陀螺仪通信** | `PB10`, `PB11`| 模拟 I2C | MPU6050 | 采集角速度和偏航角，固定在车体中心 |
| **本地操作按键** | `PE4` (`KEY0`), `PE3` (`KEY1`) | 中断/查询 | 板载按键 | 实现多菜单切换与动作使能 |
| **公共参考地** | `GND` | 系统地 | 驱动板 `GND` | **保证整个系统的控制信号参考地一致** |

## 四、 本地脱机调试指南

1.  **开机自动零偏标定**：小车上电时需保持静止，程序将自动采集 MPU6050 陀螺仪的原始漂移值进行零偏标定。
2.  **安全检测校验**：LCD 屏幕会显示 `DRV:ON` 或 `DRV:OFF`。如果未连接 `PA5 ADC` 采样线，系统将判定动力电未开启，出于保护目的会拒绝执行所有转动命令。
3.  **开环直线测试**：
    *   将履带悬空架设。
    *   通过短按 `KEY0` 切换选中项目至 `TEST LOW`，短按 `KEY1` 启动运行，检查双侧电机是否同向运转、编码器读数是否增加。
    *   长按 `KEY1`可一键进行急停（`ESTOP`）。
4.  **方位角纠偏调试**：
    *   长按 `KEY0` 切换到 `PAGE 4` (Turn Tune 页面)。
    *   选择最下方的 `[RUN]` 选项，短按 `KEY1` 启动闭环纠偏。
    *   物理旋转悬空的车体，观察两侧电机的差速响应：当车头被人为向左扭转时，左轮转速应自动降低，右轮转速自动推高以实施自反向纠偏。

## 五、 模块文件结构及说明
本工程基于 Keil uVision5 开发，核心源码说明如下：
*   `USER/main.c`: 主程序入口，管理外设配置与任务时间片轮询。
*   `BSP/chassis_bsp.c`: 板级支持包，提供定时器 PWM 输出、外部编码器捕获及 ADC 电平配置。
*   `CHASSIS/board_config.h`: 全局物理常量、限幅参数和时钟控制周期配置。
*   `CHASSIS/chassis.c`: 控制系统核心，实现轮速差速、偏航角补偿和急停故障逻辑。
*   `CHASSIS/debug_protocol.c`: 串口命令行指令接收及上位机调参指令的协议解析。
*   `CHASSIS/display_ui.c`: TFTLCD 屏幕本地可视化界面的局部刷新显示管理。
*   `CHASSIS/key_control.c`: KEY0/KEY1 物理按键的长短按扫描状态机与事件触发器。
*   `CHASSIS/battery.c`: 动力电源电压 ADC 滤波读取与断电防倒灌高阻切换。
*   `CHASSIS/motor_driver.c`: 电机驱动引脚的方向电平配置及 PWM 寄存器修改。
*   `CHASSIS/encoder_driver.c`: 两侧正交编码器计数器差值读取与转速转换。
*   `CHASSIS/pid.c`: 通用 PID 控制数学模型（位置式/增量式，抗积分饱和）。
*   `CHASSIS/servo.c` / `servo_tune.c`: 摄像头云台防抖舵机的控制与调试配置。
*   `CHASSIS/speed_tune.c` / `turn_tune.c`: 本地 LCD 速度PI与航向PID调参控制界面。
*   `SYSTEM/usart/usart.c`: 串口通信中断服务及 DMA 数据帧接收。
*   `HARDWARE/MPU6050/MPU6050.c`: MPU6050 初始化及底层数据读写。
