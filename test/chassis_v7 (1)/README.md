# STM32F103ZET6 履带式智能小车底盘下位机控制系统 (单速度PI闭环测试版)

本工程基于正点原子 STM32F103ZET6 精英开发板，设计并实现了一套用于履带式智能小车底盘的下位机控制系统。该版本（`chassis_v7` 迭代分支）专注于**高可靠性双侧速度增量式 PI 闭环控制**、**本地 LCD 状态仪表盘**、**按键本地交互测试**、**串口调试协议**以及**完善的电机驱动硬件防倒灌保护**。

本工程可作为参加研电赛、机器人大赛等移动底盘下位机控制的稳定骨架。

---

## 🛠 一、 硬件架构与引脚接线说明

为了避免精英开发板板载外设资源与履带小车底盘控制硬件发生冲突，本系统对厂商默认接线方案进行了**三处极其关键的有意改动**，确保系统运行稳定，不会因资源复用导致芯片烧毁或显示异常。

### 1. 核心资源分配与接线表

下表为 STM32F103ZET6 与 **轮趣科技 D153B (TB6612 兼容) 驱动板** 及 **MG513 编码电机** 的连接说明：

| 功能模块 | STM32 引脚 | TIM 资源 / 外设 | 驱动板 / 电机接口 | 备注与安全防冲突说明 |
| :--- | :--- | :--- | :--- | :--- |
| **左侧电机 PWM** | `PA6` | `TIM3_CH1` | D153B `PWMA` | ⚠️ **避开 LCD**：原厂示例使用 `PB1`，但精英板将 `PB1` 用作 LCD 触摸屏 SCK，故转移至 `PA6`。 |
| **右侧电机 PWM** | `PA7` | `TIM3_CH2` | D153B `PWMB` | ⚠️ **避开 LCD**：原厂示例使用 `PB0`，但精英板将 `PB0` 用作 LCD 背光控制，故转移至 `PA7`。 |
| **左侧方向控制** | `PE0`, `PE1` | 普通 GPIO | D153B `AIN1`, `AIN2` | 控制左电机正反转。 |
| **右侧方向控制** | `PE2`, `PE6` | 普通 GPIO | D153B `BIN1`, `BIN2` | 控制右电机正反转。 |
| **左路正交编码器** | `PC6`, `PC7` | `TIM8_CH1/2` | 左电机编码器 `E1A`, `E1B` | ⚠️ **避开 EEPROM**：原厂示例使用 `PB6/PB7` (TIM4)，但精英板 `PB6/PB7` 已连接板载 `24C02 EEPROM` 并带有 4.7K 上拉电阻。为保证编码器信号纯净，强制改用 `PC6/PC7` (TIM8)。接线时切勿照搬厂商示例！ |
| **右路正交编码器** | `PA0`, `PA1` | `TIM2_CH1/2` | 右电机编码器 `E2A`, `E2B` | ⚠️ **拔掉跳线帽**：精英板 `PA1` 默认接有触摸按键 `TPAD` / 模拟 `ADC`。**接线前必须拔掉板载 P7 跳线帽**，否则右路编码器将无法正确计数。 |
| **驱动板电压采样** | `PA5` | `ADC1_IN5` | D153B `ADC` 检测引脚 | ⚠️ **防倒灌安全线**：获取驱动板实时电压，用于防倒灌检测。原厂示例使用 `PA6`，因 `PA6` 被改作 PWM，故转移至 `PA5`。 |
| **LCD 状态显示** | FSMC 接口 | 并行 FSMC 数据总线 | ALIENTEK 2.8寸 TFTLCD | 本工程采用 2.8 寸 TFT 液晶屏，**不使用触摸功能**。 |
| **本地交互按键** | `PE4` (`KEY0`), `PE3` (`KEY1`) | 中断 / 查询 | 开发板板载按键 | 用于本地模式切换、参数调试、一键急停与故障清除。 |
| **共地线 (极其重要)** | `GND` | 系统地 | D153B `GND` | 必须保证 STM32 与驱动板、编码器共地，否则信号异常可能烧毁 IO！ |

## 🚀 二、 核心功能与技术特色

### 1. 双侧增量式 PI 速度控制 (TIM6, 10ms 周期)
- 底层控制环路运行在 `TIM6` 定时器中断中，控制周期为严格的 **10 ms**。
- 采用**增量式 PI 控制算法**，在离散控制系统中具有积分限幅、防饱和功能，控制平稳。
- 结合**软件 PWM 爬升斜坡限制**（默认最大步长 120 / 10ms），防止大步进速度指令导致小车电机急启急停、电池电压骤降以及电机齿轮箱受冲击。

### 2. 独家硬件安全保护：驱动板断电防反灌
- **硬件隐患**：当驱动板 D153B 12V 供电断开，但 STM32 依然通电且 GPIO 输出高电平（PWM 或方向信号）时，高电平电流会通过驱动芯片的保护二极管反向倒灌进 D153B 驱动板，导致 D153B 的电源指示灯微亮。长期反灌会导致驱动芯片与 STM32 IO 口过热甚至损坏。
- **软件防反灌保护方案**：本程序启用 `DRIVER_POWER_CHECK_ENABLE`。STM32 通过 `PA5 (ADC1)` 实时采样 D153B 驱动板的电压。
  - 当检测到驱动板未上电时（低于 3.0V），自动将 `PA6`, `PA7`, `PE0`, `PE1`, `PE2`, `PE6` 等电机相关控制引脚配置为**模拟输入/高阻状态**，彻底阻断反灌电流。
  - 同时，LCD 屏幕上会醒目地显示 `DRV:OFF` 警告，并自动拒绝任何本地或串口的电机测试命令。
  - 当驱动板重新上电（高于 4.5V）后，系统自动恢复为输出状态，LCD 显示 `DRV:ON` 并解锁控制。

### 3. LCD 屏幕超低闪烁优化
- 在 2.8 寸 TFTLCD 液晶并行屏上进行高频清屏重画会导致屏幕严重闪烁。
- 本系统通过**局部按行缓存机制**（`display_ui.c`）实现了极致的防闪烁画法：
  - 系统仅在数据内容真正发生变化时才触发重画。
  - 使用空格填充覆盖旧字符，避免了对整行或整屏使用 `LCD_Fill()` 清屏。
  - 将 UI 刷新周期设为温和的 **300 ms**，既能保证仪表的实时性，又实现了完美的无闪烁显示。

### 4. 强大的本地可视化参数调参仪表盘
通过长按/短按 `KEY0` 与 `KEY1`，用户无需连接电脑串口，即可直接在小车屏幕上查看和调节控制参数：
- **MAIN 页面**：显示当前控制模式（STOP/OPEN/VEL/COUNT）、电池电压、目标/实际速度、左右轮 PWM 输出值、故障代码以及本地选中的测试菜单。
- **ENCODER 页面**：实时显示左右编码器最近 10ms 的脉冲变化值（Delta），以及从开机以来的**脉冲累计值（TOTAL）**，极大方便手动转动履带进行编码器方向与线数校准。
- **SYSTEM 页面**：显示系统基础配置信息、当前运行时间（Uptime）、驱动板工作状态等。
- **TUNE 页面**：**核心调参利器！** 可直接在该页面用按键选择并调节左/右轮的 `KP`、`KI`、`FF前馈` 以及当前小车测试的目标速度，并一键启动/停止运行，观察动态响应。

## 📈 三、 调参日志总结与控制架构演进 (精髓)

系统调参过程完整记录在 `CHASSIS/TUNING_CHANGELOG.md` 中。底盘速度控制架构经历了以下四次关键演进：

1. **第一阶段：大比例前馈 + 纯比例 P 控制 (KI=0)**
   - *问题*：直线行驶跑偏严重。左右电机由于物理摩擦、负载差异，纯 P 控制无法消除稳态误差，必须依赖不同的前馈值（如左FF=1500，右FF=1400）勉强维持平衡，但在不同工况下缺乏自适应性。
2. **第二阶段：对齐原厂 pure PI 控制 (FF=0, KP=15.0, KI=7.0) 并引入 Start Boost (启动爆发)**
   - *问题*：架空测试时，左电机启动后振荡，右电机完全无响应。
   - *冲突分析*：`Start Boost` 在前 250ms 强制给出 2100 的 PWM 帮助克服静摩擦，导致速度瞬间飙升。PI 环路检测到严重“超速”，积分项疯狂减小，PI 输出变成巨大的负数。当 250ms 的 Boost 结束时，由于目标速度为正，负输出被限幅为 0，导致电机瞬间停转。随后 PI 重新缓慢爬升，造成严重的启停振荡与卡死。
3. **第三阶段：禁用 Start Boost，降低 PWM 爬升步长**
   - *问题*：地面试车时由于履带接地摩擦过大，FF=0 导致小车启动延迟严重。同时，由于悬空轮起步时一轮先转，底盘震动导致卡死的另一侧编码器产生虚假脉冲跳动，PI 误判定该侧已启动而清空积分，导致该侧电机永久卡死。
4. **最终阶段：高阶混合架构 (强比例 + 同等保守前馈 + 积分稳态补偿)**
   - *架构配置*：
     ```c
     SPEED_PID_DEFAULT_KP = 60.0f
     SPEED_PID_DEFAULT_KI = 3.0f
     MOTOR_LEFT_FF_DEFAULT = 1800
     MOTOR_RIGHT_FF_DEFAULT = 1800
     MOTOR_PWM_MIN_EFFECTIVE = 1800
     ```
   - *成功逻辑*：左右轮给相同的保守前馈基准（1800，低于地面起步死区 PWM）。启动瞬间，PWM 指令立刻达到 `1800 + KP * 目标`，瞬间跨越电机死区同时起步，彻底免疫震动干扰。在运行期间，两轮物理摩擦的细微差异所导致的偏航和速度差，交由温和的积分项 `KI=3.0` 进行动态累积补偿（例如左侧自动推高至 1950，右侧维持 1820），最终在**不跑偏**的情况下实现顺畅的地面带载起步。

## ⌨️ 四、 串口调试协议 (交互指令说明)

下位机 USART1 串口通信参数：**波特率 115200，8-N-1**。发送指令时请注意开启“发送新行 (CRLF)”。

### 1. 安全测试指令
- `test low`：以开环低速 PWM (2000) 进行双轮向前安全测试，检查电机旋转方向。
- `test mid`：以开环中速 PWM (2800) 进行双轮向前安全测试。
- `test high`：以开环上限 PWM (3800) 进行前向测试。
- `test left`：以开环逆时针自转测试 (左轮 -2400, 右轮 2400)。
- `test right`：以开环顺时针自转测试 (左轮 2400, 右轮 -2400)。
- `stop`：常规刹车，关闭所有 PWM。
- `estop`：软件紧急避险（紧急制动，切断输出），并设置故障标志。
- `clear`：清除急停故障状态，恢复控制使能。

### 2. 闭环控制与调参指令
- `raw L R`：开环 PWM 控制，范围 `[-3800, 3800]`。若指令绝对值小于 1800，则自动停转（死区保护）。
- `spd L R`：闭环速度控制（以 10ms 编码器脉冲计数为目标），范围 `[-25, 25]`。
- `vel V W`：线速度与角速度闭环控制，V 为线速度 (mm/s, 最大 180.0)，W 为旋转角速度 (mrad/s, 最大 800.0)。
- `pid KP KI KD`：在线覆盖双侧速度环 PID 参数。例如输入 `pid 60.0 3.0 0.0`。
- `page N`：切换本地 LCD 页面（0: MAIN, 1: ENCODER, 2: SYSTEM）。
- `status`：打印下位机当前全部状态参数（工作模式、电压、脉冲数、实时 PWM、PI 修正值等）。
- `help`：打印指令帮助信息。

## 🏁 五、 推荐测试与避坑指南

> [!IMPORTANT]
> **接线千万条，安全第一条！** 首次上电测试请务必遵循以下步骤，防止因接线错误或 PID 反向导致飞车损毁硬件。

### 步骤 1：架空测试 (基础运行确认)
1. **断开 12V 动力电池**，仅通过 USB 线为 STM32 开发板供电。
2. 检查 LCD 屏幕是否正常亮起并显示 `DRV:OFF`，电池电压应显示为 `0.00 V` 左右。
3. 拔掉精英板上的 **P7 跳线帽**。接入右编码器信号线。
4. 架空小车履带（使两个履带完全悬空，不接触任何桌面或地面）。
5. 接入 12V 动力电池，并将 D153B 的 ADC 接线引至 `PA5`，GND 共地。
6. 此时 LCD 屏幕应刷新显示 `DRV:ON`，电压显示正常的电池电压（如 `12.0 V` 上下）。
7. **按键测试**：短按 `KEY0` 将下方 `SELECT` 切换到 `TEST LOW`，短按 `KEY1` 执行。
8. 观察两侧履带是否以低速、平滑地向前转动。如果发生异常或者方向反了，立刻**长按 KEY1 触发急停**。
9. 按 `KEY0` 切换到 `STOP`，短按 `KEY1` 停车。

### 步骤 2：编码器相位校准
1. 在架空状态下，按下 `KEY0` 长按切换页面，直到进入 **ENCODER 页面**。
2. 用手手动**向前**转动左侧履带，观察 `L_TOTAL` 计数是否持续增加；手动**向前**转动右侧履带，观察 `R_TOTAL` 是否持续增加。
3. 如果向前转动时，某一侧的 `TOTAL` 计数值在持续减小，说明该侧编码器相位反了。请在 `CHASSIS/board_config.h` 中找到对应的配置，将它的符号修改取反（如将 `-1` 改为 `1`，或将 `1` 改为 `-1`）：
   ```c
   #define ENCODER_LEFT_SIGN             -1
   #define ENCODER_RIGHT_SIGN             1
   ```
4. 重新编译并烧录，确保两轮正向旋转时，Delta 值和 TOTAL 计数值均为**正数**。

### 步骤 3：防反灌功能验证
1. 在小车运动过程中，突然关闭 D153B 驱动板的 12V 供电开关。
2. 观察 D153B 板载的红色电源指示灯是否**瞬间熄灭**。如果指示灯熄灭，且 LCD 屏幕变为 `DRV:OFF`，说明防反灌保护完美生效！
3. 如果指示灯依然微亮，说明 STM32 仍有 IO 引脚处于输出高电平状态，请立刻切断系统总电源，重新检查 `DRIVER_POWER_CHECK_ENABLE` 是否设为了 `1U`，并确认 PA5 引脚的硬件接线是否牢固。
