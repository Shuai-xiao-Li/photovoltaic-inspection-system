# STM32F103ZET6 履带式智能小车底盘下位机控制系统 (速度PI + MPU6050 偏航角 PID 闭航向锁死版)

本工程基于正点原子 STM32F103ZET6 精英开发板，设计并实现了一套高阶履带式智能小车底盘的下位机控制系统。该版本（`Speed_PI_azimuth_PID` 分支）在双侧速度增量式 PI 闭环控制的基础上，**深度集成了 MPU6050 陀螺仪姿态解算**，构建了**外环绝对偏航角（Yaw）PID 航向锁死控制系统**，彻底解决了履带底盘在地面打滑、打滑系数不均或重心偏移等物理原因造成的行驶跑偏难题。

---

## 🚀 一、 为什么仅靠编码器速度环小车仍会跑偏？(核心痛点与控制演进)

在小车底盘的早期调试中（对应 `chassis_v7` 迭代版本），我们成功实现了左右双侧电机的增量式速度 PI 闭环控制：
1. **速度环局限性**：速度环的作用仅仅是保证“左侧轮子转过的编码器脉冲数 = 右侧轮子转过的脉冲数”。在架空无摩擦测试中，两轮速度响应非常完美，完全对齐。
2. **打滑与摩擦力偏差 (物理现象)**：当履带底盘落地带载行驶时，由于履带与地面的接地摩擦系数细微差异、车身重心非几何中心对称分布、以及履带车物理打滑，**即使左右侧编码器读数完全相等，它们在地面上走过的实际物理距离也是不相等的**。
3. **初始累积角度偏角**：在启动瞬间，如果右轮比左轮早转动了仅仅 0.05 秒，车头就会倾斜出一个微小的偏角。速度环“看不见”车头歪了，它只会继续维持双侧轮速相等，最终导致小车沿着倾斜后的轨迹一直走直线，产生明显的“走着走着就跑偏”现象。

### 💡 完美的控制方案：双环串级/混合控制
为了消除这种物理现象造成的偏差，本分支引入了 **MPU6050 六轴陀螺仪** 作为航向反馈：
- **内环：双侧编码器速度 PI 控制器**（控制周期 10ms，负责消除电机非线性与快速速度跟随）。
- **外环：绝对偏航角（Yaw）方位角 PID 控制器**（负责锁死小车物理航向）。
- **控制逻辑**：
  $$\text{Yaw 偏差 } e(t) = \text{Target Yaw} - \text{Actual Yaw}$$
  通过位置式 PID 计算出纠偏角速度输出量 $U_{\text{turn}}$。接着，将该纠偏量作为差速补偿，实时叠加至内环速度目标中：
  $$\text{Left Target Speed} = \text{Base Speed} - U_{\text{turn}}$$
  $$\text{Right Target Speed} = \text{Base Speed} + U_{\text{turn}}$$
  如果小车受外部摩擦向左跑偏，实际偏航角 Yaw 变小，PID 将输出正纠偏量，强制降低左侧速度目标并推高右侧速度目标，差动扭转车头，瞬间把航向“拉正”！

## ✨ 三、 核心功能与技术特色

### 1. 双环串级控制 (Yaw 绝对航向锁死 + 速度 PI)
- **姿态动态解算**：系统上电时自动对 MPU6050 进行零偏标定。通过高频高精度的姿态融合算法，获取实时且高响应的 Yaw 绝对角（角度范围 `[-180.0°, 180.0°]`）。
- **方位角 PID 控制器**：
  - 默认参数为 `KP=0.8f, KI=0.05f, KD=0.2f`。
  - 采用积分饱和限幅与微分防抖，纠偏力度适中，不会引发小车车体剧烈扭摆，并在直行阻力突变时能瞬间恢复航向。

### 2. 本地 LCD 调参双仪表盘 (Speed Tune & Turn Tune)
通过长按 `KEY0` 切换 LCD 页面，用户能开启两个完全不同的可视化本地调试系统：
- **Speed PI Tuning 页面**：实时查看与调节双侧电机各自的速度 PI 参数（`KP`/`KI`）、`FF 前馈` 以及目标运行脉冲，并实时打印两轮反馈的 PWM 和 PI 修正量。
- **Turn PID Tuning 页面 (本分支独有！)**：
  - 用以快速调试车头锁死参数。
  - 可本地实时调节：方位环比例 `KP`、积分 `KI`、微分 `KD`、目标锁死偏航角 `TGT` (以度为单位)、以及测试基准线速度 `SPD`。
  - 实时显示当前的绝对偏航角 `ACT YAW`、目标锁死角 `TGT YAW`、以及左右电机实时被差速补偿后的 PWM 指令。
  - 选中最后一项 `[STOP]/[RUN]` 并短按 `KEY1` 可一键使能航向锁定控制，直观观察底盘在受到侧向推力干扰时的“自动拉回”纠偏响应。

### 3. 驱动板断电防反灌硬件安全保护
- 依然完全保留了 `chassis_v7` 中大获成功的 `PA5 ADC` 保护机制。
- 当驱动板 12V 断电时，STM32 自动将所有 PWM 与方向引脚配置为模拟高阻输入，防止 STM32 IO 电流反向供电给驱动板（避免驱动板电源灯微亮），为整机硬件系统提供极佳的安全冗余。

### 4. LCD 无闪烁局部刷新算法
- 采用行缓冲字符串对比技术（`display_ui.c`），仅在特定行的数据值真正改变时，才使用空格填充覆盖原先字符重新打印，规避了并行屏高频擦除导致的强烈频闪，保护视力且界面极其高级。

## ⌨️ 四、 串口调试协议 (交互指令说明)

串口参数：**波特率 115200，8-N-1**。发送指令时请注意开启“发送新行 (CRLF)”。

1. **安全与模式指令**：
   - `test low/mid/high`：以开环 PWM (2000/2800/3800) 进行直线点动测试。
   - `test left/right`：开环自转测试。
   - `stop`：常规停机。
   - `estop`：一键切断所有 PWM 控制输出，并设置锁定故障，保障人身设备安全。
   - `clear`：清除 ESTOP 状态，恢复小车可控状态。
   - `status`：打印下位机底层全部状态参数（工作模式、偏航角、电池、PWM值等）。
2. **航向锁死调参指令 (本分支独有)**：
   - `pid KP KI KD`：覆盖方位外环的 PID 参数。例如输入 `pid 0.8 0.05 0.2`。
   - `vel V W`：线速度与角速度控制（外环会自动将 W 转换为目标偏航角累加，并叠加纠偏）。
   - `page N`：切换 LCD 屏幕页面（0: MAIN, 1: ENCODER, 2: SYSTEM, 3: TUNE, 4: TURN_TUNE）。

## 🏁 五、 推荐测试与避坑指南

> [!CAUTION]
> 启用偏航角外环后，一旦方位 PID 的反馈符号错误（即“负反馈”变成了“正反馈”），小车在启动瞬间不仅不会纠偏，反而会像脱缰的野马一样朝着偏航的方向疯狂加速自转！因此，**首次测试必须双人配合并在架空状态下进行**。

### 方位环安全标定与调试三步走：

1. **第一步：标定绝对偏航角 Yaw 方向**
   - 将小车完全架空，确保履带悬空。
   - 接入 12V 动力电源，使 LCD 处于 `DRV:ON` 状态。
   - 长按 `KEY0` 切换到 **Turn PID Tuning 页面**。此时屏幕中 `ACT YAW` 会显示小车的当前角度。
   - 手动用手将小车车头**逆时针（向左）**旋转。观察 `ACT YAW` 的数值是否在**持续变大（正方向增加）**。
   - 手动用手将小车车头**顺时针（向右）**旋转。观察 `ACT YAW` 是否在**持续变小（负方向减小）**。
   - ⚠️ *重要*：如果 Yaw 旋转的角度方向与上述规律相反，说明陀螺仪安装方向或姿态解算符号存在反向。必须修改底层解算符号，或者调换小车纠偏的加减符号，直至完全符合“逆时针 Yaw 增加，顺时针 Yaw 减小”的物理右手定则。

2. **第二步：架空模拟纠偏测试**
   - 进入 **Turn PID Tuning 页面**，使用按键选中最后一项 `[STOP]`，短按 `KEY1` 使其切换为 `[RUN]`。
   - 此时，架空的履带电机应当以默认基准线速度（`SPD=8` 左右）开始向前慢速转动。
   - 此时，用手水平**逆时针（向左）**扭动小车车身。由于小车向左偏，系统为了将小车拉回目标方向，应当**主动加速左侧电机，减速甚至反转右侧电机**以产生顺逆时针的恢复力矩。
   - 反之，用手水平**顺时针（向右）**扭动小车车身。系统应当**主动加速右侧电机，减速左侧电机**。
   - 如果表现完全符合上述特征，证明方位 PID 纠偏方向完全正确，且闭环反馈极度敏捷！

3. **第三步：地面试车与调参**
   - 将小车平稳放至平整地面。
   - 使能航向锁死 `[RUN]`。此时，小车将以恒定航向极其笔直地向前行驶。
   - 试着用脚踢一下或者用手推一下运动中的小车尾部，使其发生瞬间扭摆。
   - **理想现象**：小车在被推歪的瞬间，履带会发出一声急促的差速轰鸣，在 0.5 秒内自动把车头拉回原有的直线轨迹上，然后继续笔直行驶。
   - **调试建议**：如果拉回过程存在抖动或摆动，请微调减小外环的 `KP`（如从 0.8 降到 0.6）；如果拉回缓慢，可适当增加 `KP`，并微调 `KD`（如 0.2）以提供超前的阻尼分量，消除超调。
